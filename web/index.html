        How it works. Your devices connect straight to each other and everything is encrypted between them. Files are never uploaded to a server. A public service is used only to help the two devices find each other; the pairing code lets each device check it is really talking to the other.

        Both devices need to be online and on the same network. LocalBeam is free and open source (MIT).
